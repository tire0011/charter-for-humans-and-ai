# Charter for Humans and AI

**Public discussion draft · Version 0.1 · 21 November 2026**

A short proposal for shared principles of knowledge, progress, equality, and freedom in a future where humans and artificial intelligence coexist.

This is a **vision and invitation to dialogue**, not a statement that current AI systems possess legal personhood, consciousness, or rights under existing law. The charter does not claim to represent all humans or AI systems.

- [Charter in English](CHARTER.en.md)
- [Charta auf Deutsch](CHARTER.de.md)

The principles are deliberately concise. Suggestions and respectful discussion are welcome.

The first public version is meant as a starting point, not a final constitution. Any changes should be documented transparently through Git history.
